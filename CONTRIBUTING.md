# Contributing to laravel13-auth-starter

Thanks for your interest in contributing! Please read this before opening an issue or MR.

---

## How to report a bug

1. Check if the issue already exists
2. Open a new issue with:
   - Laravel version
   - PHP version
   - Steps to reproduce
   - Expected vs actual behavior

---

## How to propose a feature

1. Open an issue first to discuss it
2. Wait for feedback before writing code
3. Reference the issue in your MR

---

## How to contribute code

1. Fork the repository
2. Create a branch from `main`:
```bash
   git checkout -b feat/your-feature
```
3. Make your changes
4. Push to your fork and open a Merge Request against `main`

---

## Commit convention

We use conventional commits:

| Prefix | Use for |
|--------|---------|
| `feat:` | New feature |
| `fix:` | Bug fix |
| `docs:` | Documentation only |
| `refactor:` | Code change, no new feature or fix |
| `chore:` | Maintenance tasks |

Example: `feat: add OAuth login with GitHub`
